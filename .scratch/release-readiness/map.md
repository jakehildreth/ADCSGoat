# Release Readiness

## Destination

Every blocking gate in `Research/RELEASE-CHECKLIST.md` resolved to a decision. The map is done when the way to a publishable release is clear — execution of the resulting plan is a separate effort.

## Notes

- Domain: ADCSGoat, a PowerShell module that deploys a deliberately vulnerable AD CS lab. Build tooling: PSPublishModule. Vendored dependency: PSCertutil.
- Plan-only map: tickets resolve decisions, not deliverables. All tickets are grilling (HITL) — Jake makes the calls.
- Source document: `Research/RELEASE-CHECKLIST.md` (baseline: HEAD `7b8c203`, source manifest `2026.7.220804`, Gallery latest `2026.7.221210`, latest tag `0.4.1`).
- Facts about PSPublishModule behavior get researched inline mid-grill when a decision needs them, not as separate tickets.

## Decisions so far

<!-- one line per closed ticket: gist + link -->

- [Version scheme](issues/01-version-scheme.md) — CalVer everywhere going forward; build's `-CalVer` parameter is the single source of truth, back-written to source manifest, changelog, and Git tag; changelog regenerated by git-cliff at release; emojis allowed in changelog headers.
- [Build fails on vendored-dep save error](issues/02-build-fails-on-vendored-dep-error.md) — targeted hardening: `-ErrorAction Stop` on `Save-Module`, `throw` in post-build guards, pinned-version folder check (stale folders currently mask failed saves), non-zero exit from `Build-Module.ps1`.
